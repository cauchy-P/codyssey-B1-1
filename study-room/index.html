테마 버튼 하나를 세 기술이 함께 만든다

HTML — 대상

버튼, id, class, 접근성 상태를 문서에 만든다.

<button id="theme-toggle"
 class="icon-button">◐</button>

CSS — 표시

같은 버튼의 크기, 원형 모양, 색상을 적용한다.

.icon-button {
 border-radius: 50%;
}

JavaScript — 변화

클릭을 감지하고 테마 상태와 DOM 속성을 바꾼다.

button.addEventListener(
 'click', renderTheme
);
브라우저 결과HTML: 버튼이 문서에 존재합니다.

`await fetch()`에서 실제로 일어나는 일

1. JS가 fetch 호출
2. 네트워크 요청 진행
3. 메인 쓰레드는 다른 이벤트 처리
4. 응답 도착
5. await 뒤 코드 재개

`await`는 브라우저 전체가 아니라 해당 async 함수의 뒷부분만 미룹니다.

같은 요청도 결과에 따라 화면 상태가 달라진다

empty
정상이나 결과 없음
error
오류와 재시도
